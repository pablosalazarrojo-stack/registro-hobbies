# Registro de Hobbies

Registro de alumnos (nombre, WhatsApp, tres hobbies y carrera). El administrador forma parejas de distinta carrera según los hobbies en común y las libera; cada persona ve a su pareja en la app.

- `index.html`: la app (GitHub Pages).
- `Code.gs`: el código que vive en Apps Script y guarda los datos en una hoja de Google privada.
